# Project Brief

## 프로젝트 한 줄 설명

기존 PHP 기반 B2B 반려동물 쇼핑몰을 Next.js + TypeScript 기반으로 리뉴얼하는 포트폴리오 프로젝트.

## 대상 사이트

- http://www.giftpet.kr/shop/
- 내부 페이지 이동 시 shop3.mjsoft.co 도메인으로 이동하는 구조가 있음
- HTTP만 정상 접근되는 것으로 보임

## 프로젝트 성격

이 프로젝트는 실제 운영 쇼핑몰의 전체 기능을 복제하는 프로젝트가 아니라, 확인 가능한 핵심 화면을 기준으로 프론트엔드 리뉴얼 MVP를 구현하는 프로젝트이다.

## 프로젝트 목적

- 구직용 포트폴리오 프로젝트 제작
- TypeScript 기반 프론트엔드 프로젝트 경험 보완
- 기존 사이트의 정보 구조, 상품 탐색 흐름, 반응형 UI 개선

## 1차 목표

- 메인 페이지
- 상품 목록 페이지
- 상품 상세 페이지
- mock data 기반 구현
- Vercel 배포

## 제외 범위

- 로그인

- 장바구니
